# Тихая глубина

Одиночная 2D-игра о фридайвинге для Android. Фридайвер исследует рифы, гроты, Восточный шельф и Грозовой желоб. В восьми зонах спрятано 58 сокровищ. Самые ценные реликвии охраняют три вида электроскатов.

Задержка дыхания ограничивает время погружения. Кислород восстанавливается постепенно, пока дайвер на поверхности. Опыт за находки и побеждённых хищников засчитывается после успешного всплытия. Нож для ближнего боя доступен сразу. В магазине на поверхности можно купить и улучшить гарпун, а также увеличить скорость, запас кислорода и число жизней. Прогресс сохраняется на устройстве, игра работает в офлайне.

Три уровня электрозащиты дают иммунитет к разрядам скатов соответствующей силы и слабее. Одноразовый набор для мин стоит 100 ОП. Подплывите к мине и нажмите **Наборы** или **R**, чтобы израсходовать один набор.

Защитный костюм меняет цвет с уровнем улучшения и вспыхивает при поглощении разряда. Опасные патрули редко появляются у поверхности. На глубине вероятность встречи выше.

Базового заряда хватает на 2 секунды рывка. Полное восстановление занимает 10 секунд. Длительность рывка и время зарядки улучшаются отдельно за ОП.

На глубине 28–92 м противники возвращаются на прежние места через 90 секунд, а сокровища через 2 минуты. Отсчёт начинается после начисления опыта на поверхности и продолжается при закрытой игре. Глубинные реликвии остаются уникальными.

Гибель дайвера сбрасывает опыт, покупки и находки экспедиции. Рекорд глубины и настройка звука сохраняются.

## Установка на Android

Требуется Android 7.0 или новее с обновлённым Android System WebView. Скачайте `quiet-depth.apk` из [Releases](https://github.com/dharmapredur-cyber/Deep-silent/releases) и откройте его на телефоне. Это отладочная сборка для ручной установки.

Для перехода с прежних сборок потребуется переустановка из-за смены отладочной подписи. Удаление приложения очищает локальный прогресс.

APK каждого коммита доступен в **Actions → Android APK → Artifacts → quiet-depth-apk**. В этом случае извлеките APK из ZIP перед установкой.

На телефоне игра открывается в альбомной ориентации. Слева расположен джойстик, справа — кнопки ножа, гарпуна и рывка. Добычу можно искать по карте в правом верхнем углу.

## Сборка и проверка

GitHub Actions собирает APK и запускает Android Lint при каждом push и pull request. Локально используйте JDK 17, Gradle 8.11.1 и Android SDK 35.

```sh
gradle :app:lintDebug :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Игровые ресурсы поставляются внутри APK. Шрифт Manrope распространяется под лицензией SIL OFL, текст которой включён в `app/src/main/assets/art/Manrope-OFL.txt`.

Игру также можно запустить в браузере.

```sh
python3 -m http.server 3000 --directory app/src/main/assets
```

Откройте `http://localhost:3000`. Плавание — WASD или стрелки, рывок — Shift, нож — F, гарпун — пробел, набор для мин — R, карта — M, снаряжение — E, пауза — Esc.
